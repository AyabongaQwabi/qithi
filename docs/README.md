# Docs Structure

This `docs` folder is organized by content type and date.

## Folders

- `docs/blog/`: long-form article drafts and blog-related source files.
- `docs/prompts/`: dated implementation prompt docs and prompt index.
- `docs/research/`: research notes and source material grouped by batch.

## Research Batches

- `docs/research/2026-06-foundation/`
  - `notes/`: markdown research notes and thesis drafts
  - `papers/`: PDF source documents
  - `media/`: image assets and maps
  - `data/`: bibliographies and CSV exports
  - `archive/`: retained duplicates or superseded drafts
- `docs/research/2026-07-lesotho-notes/`: Lesotho-focused Thembu/San note series.
- `docs/research/2026-07-topic-notes/`: topical notes captured in July.

## Naming Convention

- Prefer: `YYYY-MM-DD-topic-slug.ext`
- Use lowercase kebab-case for slugs.
- Keep spaces out of filenames.
- Use `-part-2`, `-part-3` for sequels.
- Move near-duplicate files into `archive/` with `-duplicate` suffix.
